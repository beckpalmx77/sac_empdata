🛠️ 4. ขั้นตอนการติดตั้งและตั้งค่าใช้งาน (Implementation Guide)

สามารถทำได้ 2 แนวทาง โดยแนะนำ แนวทางที่ 1 (Native PHP Extension) มากที่สุดเพราะมีประสิทธิภาพสูงสุดและไม่ต้องแก้โค้ดเลย

1

เตรียม Redis Server

เลือกวิธีติดตั้ง Redis Server ตามสภาพแวดล้อมที่ใช้งาน:

  • สำหรับเครื่อง Dev (Windows / WAMP):
    • ทางเลือก ก (ง่ายที่สุดผ่าน Docker): 
    docker run -d --name redis-session -p 6379:6379 redis:alpine --requirepass "SacEmp@2026"
    • ทางเลือก ข (ผ่าน WSL2 Ubuntu): 
    sudo apt update && sudo apt install redis-server
sudo service redis-server start
    • ทางเลือก ค (ใช้ Memurai สำหรับ Windows โดยตรง): ดาวน์โหลดตัวติดตั้ง MSI จาก memurai.com แล้วสั่งรัน Service บน Windows ได้ทันที
  • สำหรับเครื่องเซิร์ฟเวอร์จริง (Linux Production Server): 
    sudo apt update
sudo apt install redis-server -y
sudo systemctl enable redis-server && sudo systemctl start redis-server
2

ติดตั้ง PHP Redis Extension (php_redis.dll) บน WAMP

เครื่องปัจจุบันของท่านรัน PHP 8.3.14 (ZTS / Thread-Safe, Visual C++ 2019, x64)

  1. ดาวน์โหลดไฟล์ php_redis DLL สำหรับ Windows จาก PECL:
    https://pecl.php.net/package/redis
    เลือกรุ่น: 8.3 Thread Safe (TS) x64
  2. แตกไฟล์ zip แล้วคัดลอกไฟล์ php_redis.dll ไปวางไว้ที่: 
    D:\wamp64\bin\php\php8.3.14\ext\php_redis.dll
3

ตั้งค่าไฟล์คอนฟิก php.ini ของ Apache

เปิดไฟล์ D:\wamp64\bin\php\php8.3.14\phpForApache.ini (หรือคลิกซ้ายที่ไอคอน WAMP เขียว > PHP > php.ini) แล้วเพิ่ม/แก้ไขค่าดังนี้:

phpForApache.ini
; 1. เปิดใช้งาน Extension Redis
extension=redis

; 2. กำหนดให้ Session บันทึกลง Redis แทน Files
session.save_handler = redis

; 3. กำหนด IP / Port / รหัสผ่าน และคำนำหน้าคีย์
; รูปแบบ: tcp://HOST:PORT?auth=PASSWORD&prefix=KEY_PREFIX
session.save_path = "tcp://127.0.0.1:6379?auth=SacEmp@2026&prefix=SAC_SESSION:"

; 4. ตั้งเวลาหมดอายุของ Session (วินาที) เช่น 2 ชั่วโมง (7200 วินาที)
session.gc_maxlifetime = 7200

; 5. เปิด Session Locking เพื่อป้องกัน Race Condition จาก AJAX
redis.session.locking_enabled = 1
redis.session.lock_wait_time = 20000
redis.session.lock_max_retries = 300

จากนั้นคลิกซ้ายที่ไอคอน WAMP แล้วเลือก "Restart All Services" เพื่อให้ Apache โหลดคอนฟิกใหม่

📦 5. ทางเลือกสำรอง: ใช้ Composer Package (Predis)

หากในสภาพแวดล้อมบางแห่ง (เช่น Shared Hosting) ไม่สามารถลง php_redis.dll ได้ สามารถใช้แพ็กเกจ PHP ล้วนผ่าน Composer ได้เช่นกัน:

# ติดตั้ง Predis ในโปรเจกต์
composer require predis/predis

จากนั้นสร้างไฟล์ config/redis_session_handler.php:

config/redis_session_handler.php
<?php
require_once __DIR__ . '/../vendor/autoload.php';

$client = new Predis\Client([
    'scheme' => 'tcp',
    'host'   => '127.0.0.1',
    'port'   => 6379,
    'password' => 'SacEmp@2026',
]);

$handler = new Predis\Session\Handler($client, [
    'gc_maxlifetime' => 7200,
    'prefix' => 'SAC_SESSION:'
]);

$handler->register();
// เมื่อเรียก session_start() จะใช้ Predis ทันที

และตั้งค่า auto_prepend_file ใน .htaccess เพื่อให้ไฟล์นี้ถูกเรียกทำงานก่อนทุกไฟล์โดยไม่ต้องแก้ 93 ไฟล์เดิม:

php_value auto_prepend_file "D:/website/sac_empdata/config/redis_session_handler.php"

⚠️ 6. ข้อควรระวังและแนวทางปฏิบัติที่ดีที่สุด (Production Best Practices)

🔒 1. การรักษาความปลอดภัย (Security)

• ต้องตั้งรหัสผ่าน requirepass ใน redis.conf เสมอ
• ไม่ควรเปิดพอร์ต 6379 สู่สาธารณะ (Public Internet) ให้ Bind กับ 127.0.0.1 หรือ Private Subnet เท่านั้น
• มีการตั้ง Prefix คีย์ชัดเจน เช่น SAC_SESSION: เพื่อป้องกันคีย์ชนกับข้อมูลแคชอื่น

💾 2. การจัดการหน่วยความจำ (Memory Eviction)

หากเซิร์ฟเวอร์มีแรมจำกัด ควรตั้งค่าใน redis.conf:
maxmemory 512mb (หรือตามขนาดที่เหมาะสม)
maxmemory-policy volatile-ttl
เพื่อให้ Redis ลบ Session ที่ใกล้หมดอายุที่สุดทิ้งก่อนหาก RAM ใกล้เต็ม ป้องกันไม่ให้ Redis Crash

🔄 3. ความพร้อมใช้งานสูง (High Availability / SPoF)

หาก Redis ดับ ระบบจะไม่สามารถยืนยันตัวตนผู้ใช้ได้:
• เปิดใช้งาน Snapshot save 900 1 หรือ appendonly yes ใน Redis เพื่อให้ข้อมูลไม่หายเวลารีสตาร์ตเซิร์ฟเวอร์
• ในระดับ Enterprise สามารถทำ Redis Sentinel หรือ Redis Cluster เพื่อทำ Auto-Failover

⏱️ 4. Concurrency & Session Locking

โปรเจกต์นี้มีหน้าจอที่มีการเรียก AJAX พร้อมกันหลายตัว ควรเปิด redis.session.locking_enabled = 1 ใน php.ini เพื่อป้องกันปัญหา Race Condition ข้อมูล Session ถูกเขียนทับกัน
